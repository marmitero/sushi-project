# Constituição do Projeto

A constituição integral é `docs/master-prompt.md` (fonte da verdade). Este arquivo resume os pontos inegociáveis para referência rápida.

## Identidade

Sushiventure Idle Tycoon — idle/tycoon de sushi com torre vertical, automação, expansão por cidades e renascimento com Pontos de Sucesso. Web (retrato) primeiro; Android depois.

## Pilares

Visual (torre central) · Progressão · Automação · Decisões significativas · Continuidade (offline+prestígio) · Integridade · Expansão.

## Regras inegociáveis (resumo)

1. Não virar site de cards/painel admin. 2. Torre é o jogo. 3. Sem placeholders permanentes p/ assets existentes. 4. Sem arte genérica/IA quando o kit supre. 5. Não simular integração real. 6-8. Economia centralizada, débitos e recompensas corretos e não-duplicados. 9. Botão funcional = efeito real. 10. Não apagar assets/licença/histórico. 11. Sem segredos no frontend/GitHub. 12. Não desativar testes/TS/validações. 13. Documentação contínua. 14. Sistema completo só com regras/erros/persistência testados. 15. MVP é a 1ª etapa. 16. Não pushar etapa quebrada. 17. Sem libs/serviços pagos sem avaliação.

## Hierarquia de decisão

Preservar trabalho → cumprir constituição → jogável/coerente → integridade econômica/saves → compatibilidade web → extensibilidade → documentação/testes → desempenho → extras.

## Fluxo por etapa

Implementar → testar → documentar → atualizar AI_STATE/changelog → commit+push (quando houver acesso) → relatório objetivo.
